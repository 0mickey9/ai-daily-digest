# ai-daily-digest
AI Daily Digest  is a system that analyze employee activity
and generates personalized updates for each team member.

The goal is to reduce irrelevant information during daily meetings.



- employee:
  name, team_name, role
- activity:
  activity_creator, activity_feature, project_name, place_in_system, created_at
- project:
  name,description,priority,status,created_at
- team:
  members, projects, current_projects

# Data Platform
components:
- client_data
- employee_data
- authentication
- model_data
- train_data
- test_data
